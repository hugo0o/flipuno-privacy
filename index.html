Política de privacidad de Flipuno

Última actualización: 26 de noviembre de 2026

Esta Política de privacidad explica cómo Flipuno trata la información cuando utilizas nuestra aplicación.

1. Responsable de la aplicación

Flipuno es una aplicación diseñada para ayudarte a tomar decisiones entre dos opciones mediante un lanzamiento de moneda virtual.

Responsable: Hugonomore
Correo de contacto: vihugobx@gmail.com

2. Información que procesa la aplicación

Flipuno permite introducir dos opciones de texto libre para realizar una elección aleatoria.

La información introducida puede incluir datos personales o sensibles si el usuario decide escribirlos. Por este motivo, recomendamos no introducir información confidencial.

Las opciones y el resultado se procesan directamente en el dispositivo. La aplicación no solicita nombres, correos electrónicos, números telefónicos, ubicación ni información de cuentas.

3. Almacenamiento de información

Flipuno no requiere crear una cuenta ni iniciar sesión.

La versión actual no cuenta con servidores propios, bases de datos en la nube ni funciones de sincronización. Las opciones, resultados y reacciones se mantienen temporalmente en la memoria de la aplicación y no se guardan de forma persistente mediante mecanismos propios de almacenamiento.

4. Compartir información con otras aplicaciones

Flipuno permite compartir el resultado de una elección mediante la función de compartir de Android.

Cuando utilizas esta función, se envía al selector de compartir del dispositivo un texto que puede incluir:

  • La opción seleccionada.
  • La frase de reacción, si existe.
  • Un mensaje fijo relacionado con Flipuno.

La opción que no fue seleccionada no se incluye en ese mensaje.

El usuario decide qué aplicación o destinatario recibe el contenido. Una vez compartida la información, el tratamiento que realice el destinatario depende de sus propias políticas y prácticas de privacidad.

Flipuno no controla el almacenamiento o uso posterior que hagan esas aplicaciones de terceros.

5. Servicios de terceros y publicidad

La versión actual de Flipuno no incorpora servicios propios de publicidad, analítica, seguimiento de usuarios ni informes de errores.

La función para compartir utiliza el mecanismo proporcionado por Android y la biblioteca de integración correspondiente.

Las aplicaciones externas que el usuario elija para compartir pueden tener sus propias prácticas de recopilación y tratamiento de información.

6. Permisos del dispositivo

La versión de producción revisada no declara permisos para acceder a ubicación, contactos, cámara, micrófono o almacenamiento del usuario.

La función de compartir utiliza los mecanismos del sistema Android para ofrecer los destinos disponibles.

7. Privacidad de menores

Flipuno no solicita información personal ni requiere crear cuentas. Los padres o tutores deben supervisar el uso que los menores hagan de aplicaciones y dispositivos, especialmente cuando se introduzca o comparta información mediante texto libre.

8. Seguridad

Flipuno está diseñada para procesar las opciones directamente en el dispositivo y no cuenta con un servidor propio que almacene esos contenidos.

Sin embargo, ningún sistema o dispositivo puede garantizar una seguridad absoluta. El tratamiento de información por parte del sistema operativo, el teclado o las aplicaciones externas está sujeto a sus propias políticas.

9. Cambios en esta política

Esta Política de privacidad puede actualizarse cuando se incorporen nuevas funciones o cambie el funcionamiento de Flipuno.

La versión vigente estará disponible en esta misma dirección web.
